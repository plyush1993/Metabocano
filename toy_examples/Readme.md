# Toy examples for input
> [!WARNING]
> Should be used only to check the performance of the App and to refer to the data format of inputs.

---
- `xcms` table output was generated as follows:
```r
library(xcms)
library(MsExperiment)
library(MSnbase)

pd <- data.frame(...)
xdata <- readMsExperiment(... , sampleData = pd) or readMSData(... , pdata = pd)

cwp <- CentWaveParam(...)
xdata <- findChromPeaks(... , param = cwp)
owp <- ObiwarpParam(...)
xdata <- adjustRtime(... , param = owp)
pdp <- PeakDensityParam(...)
xdata <- groupChromPeaks(... , param = pdp)
cpp <- ChromPeakAreaParam(...) # or FillChromPeaksParam(...)
xdata <- fillChromPeaks(... , param = cpp)

fvals <- featureValues(xdata, value = "into")
fdef <- featureDefinitions(xdata)[, c("mzmed", "mzmin", "mzmax", "rtmed", "rtmin", "rtmax")]
fvals <- cbind(Row.names = rownames(fdef), fdef, fvals)

write.csv(fvals, "... .csv", row.names = F)
```
---
- `mzMine` table output was generated by the module *`Feature list methods -> Export feature list -> Export molecular network files -> Options: filter rows: MS2 or ION IDENTITY (for DDA) or ALL (for SCAN), no normalization, Intensity - Area, CSV export - Simple`*. File ends with *`_quant.csv`*.
---
- `MS-Dial` output was generated by the module *`Export -> Alignment result -> Selected Options: Raw data (Area); format csv; trim content for Excel`*.
